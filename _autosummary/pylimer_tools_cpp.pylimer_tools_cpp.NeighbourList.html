List all atoms that are close to a given one.

It is possible to request it within a new cutoff, though the underlying neighbour list will not be regenerated. For performance reasons, it is recommended to initialize a new NeighbourList if you require a differnt cutoff, depending on your use case.

You can use a negative value for the newCutoff to use the cutoff used for filling the neighbour list buckets.
