getGammaFactor(self: pylimer_tools_cpp.pylimer_tools_cpp.MEHPForceRelaxation, r0squared: float = -1.0, nrOfChains: int = -1) → float#

Computes the gamma factor as part of the ANT/MEHP formulism, i.e.:

\(\Gamma = \langle\gamma_{\eta}\rangle\), with \(\gamma_{\eta} = \frac{\bar{r_{\eta}}^2}{R_{0,\eta}^2}\), which you can use as \(G_{\mathrm{ANT}} = \Gamma \nu k_B T\), where \(\eta\) is the index of a particular strand, \(R_{0}^2\) is the melt mean square end to end distance, in phantom systems \($= N_{\eta}*b^2$\) \(N_{\eta}\) is the number of atoms in this strand \(\eta\), \(b\) its mean square bond length, \(T\) the temperature and \(k_B\) Boltzmann’s constant.

Parameters:

  • r0squared – The denominator in the equation of \(\Gamma\). If \(-1.0\) (default), the network is used for determination (which is not accurate). For phantom systems, the correct value is \(Nb^2\). For other systems, the value could be determined by ~pylimer_tools_cpp.pylimer_tools_cpp.Universe.computeMeanEndToEndDistance on the melt system.

  • nrOfChains – the value to normalize the sum of square distances by. Usually (and default if \(< 0\)) the nr of chains.

Get the atom ids of the nodes that are considered active.

Parameters:

runForceRelaxation(self: pylimer_tools_cpp.pylimer_tools_cpp.MEHPForceRelaxation, algorithm: str = 'LD_MMA', maxNrOfSteps: int = 250000, xTolerance: float = 1e-12, fTolerance: float = 1e-09) → None#

Run the simulation. Note that the final state of the minimization is persisted and reused if you use this method again. This is useful if you want to run a global optimization first and add a local one afterwards. As a consequence though, you cannot simply benchmark only this method; you must include the setup.

Parameters:

  • algorithm – The algorithm to use for the force relaxation. Choices: see NLopt Algorithms

  • maxNrOfSteps – The maximum number of steps to do during the simulation.

  • xTolerance – The tolerance of the displacements as an exit condition.

  • fTolerance – The tolerance of the force as an exit condition.

  • is2d – Specify true if you want to evaluate the force relation only in x and y direction.
