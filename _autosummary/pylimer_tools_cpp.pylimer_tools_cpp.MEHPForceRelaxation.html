getGammaEq(self: pylimer_tools_cpp.pylimer_tools_cpp.MEHPForceRelaxation) → float#

Computes the gamma factor as part of the ANT/MEHP formulism, i.e.:

\Gamma = \langle\gamma_{\eta}\rangle, with \gamma_{\eta} = \frac{\bar{r_{\eta}}^2}{N_{\eta} b^2}, which you can use as G_{\mathrm{ANT}} = \Gamma \nu k_B T, where \eta is the index of a particular strand, N_{\eta} is the number of atoms in this strand \eta, b its mean square bond length, T the temperature and k_B Boltzmann’s constant.

runForceRelaxation(self: pylimer_tools_cpp.pylimer_tools_cpp.MEHPForceRelaxation, crosslinkerType: int = 2, maxNrOfSteps: int = 250000, tolerance: float = 1e-08, Nb2: float = - 1.0, is2d: bool = False, dt: float = 0.077, kappa: float = 1.0) → None#

Run the simulation.

Parameters

  • crosslinkerType – The atom type of the cross-linkers. Needed to reduce the network.

  • maxNrOfSteps – The maximum number of steps to do during the simulation.

  • tolerance – The tolerance of the force as an exit condition.

  • Nb2 – The denominator in the equation of \Gamma (see: getGammaEq()). If -1.0 (default), the network is used for determination.

  • is2d – Specify true if you want to evaluate the force relation only in x and y direction.
