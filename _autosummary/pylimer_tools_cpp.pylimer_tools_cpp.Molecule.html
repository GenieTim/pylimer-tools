getEdges(self: pylimer_tools_cpp.pylimer_tools_cpp.Molecule) → Dict[str, List[int]]#

Get all bonds. Returns a dict with three properties: ‘edge_from’, ‘edge_to’ and ‘edge_type’. The order is not necessarily related to any structural property.

Note

The integer values returned refer to the vertex ids, not the atom ids. Use getAtomIdByIdx() to translate them to atom ids, or getBonds() to have that done for you.
