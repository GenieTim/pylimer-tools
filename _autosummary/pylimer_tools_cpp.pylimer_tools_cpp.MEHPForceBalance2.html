getGammaFactor(self: pylimer_tools_cpp.pylimer_tools_cpp.MEHPForceBalance2, r0squared: float = -1.0, nrOfChains: int = -1) → float#

Computes the gamma factor as part of the ANT/MEHP formulism, i.e.:

\(\Gamma = \langle\gamma_{\eta}\rangle\), with \(\gamma_{\eta} = \frac{\bar{r_{\eta}}^2}{R_{0,\eta}^2}\), which you can use as \(G_{\mathrm{ANT}} = \Gamma \nu k_B T\), where \(\eta\) is the index of a particular strand, \(R_{0}^2\) is the melt mean square end to end distance, in phantom systems \($= N_{\eta}*b^2$\) \(N_{\eta}\) is the number of atoms in this strand \(\eta\), \(b\) its mean square bond length, \(T\) the temperature and \(k_B\) Boltzmann’s constant.

Parameters:

  • r0squared – The denominator in the equation of \(\Gamma\). If \(-1.0\) (default), the network is used for determination (which is not accurate). For phantom systems, the correct value is \(Nb^2\). For other systems, the value could be determined by ~pylimer_tools_cpp.pylimer_tools_cpp.Universe.computeMeanEndToEndDistance on the melt system.

  • nrOfChains – the value to normalize the sum of square distances by. Usually (and default if \(< 0\)) the nr of chains.

Get the atom ids of the nodes that are considered active.

Parameters:

  • tolerance – springs under this length are considered inactive. A node is active if it has > 2 active springs.

  • minimumNrOfActiveConnections – A node is active if it has equal or more than this number of active springs.

  • maximumNrOfActiveConnections – A node is active if it has equal or less than this number of active springs. Use a value < 0 to indicate that there is no maximum number of active connections.
