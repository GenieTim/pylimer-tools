KPM vs. Full Eigenvalue Normal Mode Analysis for PDMS Networks
==============================================================

Normal Mode Analysis (NMA) in :class:`~pylimer_tools_cpp.NormalModeAnalyzer`
predicts the linear viscoelastic storage modulus :math:`G'(\omega)` and loss
modulus :math:`G''(\omega)` of entangled polymer networks from their bead-spring
connectivity graph (:cite:t:`gusev_molecular_2024`). Computing the full
eigenvalue spectrum scales as :math:`\mathcal{O}(N_{\text{atoms}}^3)`, which
quickly becomes prohibitive for realistic representative volume elements (RVEs).
The **Kernel Polynomial Method (KPM)** approximates the spectral density using
Chebyshev moments and stochastic trace estimation in :math:`\mathcal{O}(N_{\text{atoms}})`
time.

Here we compare KPM (with :math:`M = 1024` Chebyshev moments and :math:`20`
Rademacher random vectors) against full eigenvalue decomposition for realistic
Gaussian bead-spring models of polydimethylsiloxane (PDMS,
:math:`\rho_{\text{bead}} \approx 2.23\,\text{nm}^{-3}`,
:math:`\rho_{\text{ent}} \approx 0.0608\,\text{nm}^{-3}`,
:math:`\langle b^2 \rangle \approx 1.11\,\text{nm}^2`) generated via
:class:`~pylimer_tools_cpp.MCUniverseGenerator` with on-demand entanglement
sampling (:meth:`~pylimer_tools_cpp.MCUniverseGenerator.sample_entanglements`).
We examine:

1. **Chain length** :math:`N`,
2. **Cross-link conversion** :math:`p`,
3. **Stoichiometric imbalance** :math:`r = f N_{\text{xlinks}} / (2 N_{\text{strands}})`, and
4. **Representative volume, sample count, and computational scaling**.

Single PDMS Realization with On-Demand Entanglement Sampling
------------------------------------------------------------
Using :func:`~pylimer_tools.io.bead_spring_parameter_provider.get_parameters_for_polymer`
with ``ParameterType.GAUSSIAN``, we generate a :math:`L = 12\,\text{nm}` PDMS
network, sample entanglements on demand, add the entanglement springs as bonds
in the generated :class:`~pylimer_tools_cpp.Universe`, and compare exact vs.
KPM moduli.

.. GENERATED FROM PYTHON SOURCE LINES 68-141

.. code-block:: Python


    params = get_parameters_for_polymer("PDMS", parameter_type=ParameterType.GAUSSIAN)
    assert isinstance(params, Parameters)
    dist_unit = params.get("distance_units")
    b = params.get("<b>").to(dist_unit).magnitude
    b2 = params.get("<b^2>").to(dist_unit**2).magnitude
    gamma_conv = params.get_gamma_conversion_factor().to("MPa").magnitude

    box_l = 12.0
    vol = box_l**3
    strand_len, p_demo, r_demo = 100, 0.95, 1.0
    n_strands = int(round(params.get_bead_density() * vol / (strand_len + 0.5 * r_demo)))
    n_xlinks = int(round(0.5 * r_demo * n_strands))

    gen = pt.MCUniverseGenerator(box_l, box_l, box_l)
    gen.set_seed(42)
    gen.config_nr_of_mc_steps(0)
    gen.set_bead_distance(b)
    gen.set_mean_squared_bead_distance(b2)
    gen.add_strands(n_strands, [strand_len] * n_strands)
    gen.add_crosslinkers(n_xlinks, 4)
    gen.link_strands_to_conversion(p_demo)

    es = gen.sample_entanglements(
        nr_of_entanglements_to_sample=int(params.get_entanglement_density() * vol),
        upper_cutoff=params.get_sampling_cutoff(),
        seed="demo_nma",
        filtering_mode=pt.EntanglementFilteringMode.OMIT_INACTIVE,
    )
    atom_pairs = es.to_atom_pair_entanglements(gen.get_crosslinker_universe())

    universe = gen.get_universe()
    pairs = atom_pairs.pairs_of_atoms
    if pairs:
        universe.add_bonds([pair[0] for pair in pairs], [pair[1] for pair in pairs])

    edges = universe.get_edges()
    nma = pt.NormalModeAnalyzer(
        edges["edge_from"], edges["edge_to"], universe.get_nr_of_atoms()
    )

    freqs_demo = np.logspace(-3, 2, 50)
    t0 = time.perf_counter()
    nma.find_all_eigenvalues(
        solver=pt.NormalModeSolver.AUTO,
        compute_eigenvectors=False,
        decompose_components=True,
    )
    gp_exact_demo = nma.evaluate_storage_modulus(freqs_demo) * gamma_conv / vol
    t_exact_demo = time.perf_counter() - t0

    t0 = time.perf_counter()
    gp_kpm_demo = (
        nma.evaluate_storage_modulus_kpm(
            freqs_demo,
            num_moments=1024,
            num_random_vectors=20,
            num_quadrature_points=2048,
        )
        * gamma_conv
        / vol
    )
    t_kpm_demo = time.perf_counter() - t0
    print(
        f"Demo PDMS box (L={box_l:.0f} nm, N_atoms={universe.get_nr_of_atoms()}, "
        f"N_ent={len(pairs)}): Exact={t_exact_demo:.2f}s, KPM={t_kpm_demo:.2f}s"
    )

    cache_path = get_example_cache_path(
        "kpm_vs_exact_pdms_cache.npz", "normal_mode_analysis"
    )
    data = load_or_compute_cache(cache_path, run_kpm_vs_exact_pdms_study)

Effect of Chain Length (:math:`N`)
----------------------------------
Varying the precursor strand length :math:`N \in \{50, 100, 200, 400\}` at
fixed :math:`p = 0.95` and :math:`r = 1.0` (:math:`L = 14\,\text{nm}`) shows
that shorter strands (:math:`N = 50`) shift the relaxation transition toward
higher frequencies and raise the low-frequency storage modulus :math:`G'(\omega)`
due to the higher cross-link density. KPM reproduces both :math:`G'(\omega)`
and :math:`G''(\omega)` accurately across the transition and Rouse regimes
(:math:`\omega\tau_0 \gtrsim 10^{-2}`), with minor stochastic/resolution
deviations only in the lowest-frequency tail where very few eigenvalues
reside.

Effect of Cross-link Conversion (:math:`p`)
-------------------------------------------
Varying the cross-link conversion :math:`p \in \{0.75, 0.85, 0.925, 0.98\}` at
:math:`N = 100` and :math:`r = 1.0` approaches the classical gelation threshold
:math:`p_{\text{gel}} = 1 / \sqrt{r(f - 1)} \approx 0.577` from above. Lower
conversion reduces the elastically active network fraction and increases the
abundance of dangling and soluble modes, softening :math:`G'(\omega)` at low
frequencies while leaving the high-frequency segmental Rouse response
(:math:`\omega\tau_0 \gtrsim 0.1`) largely unchanged. KPM captures this
conversion-dependent softening faithfully without computing any eigenvalues.

Effect of Stoichiometric Imbalance (:math:`r`)
----------------------------------------------
Varying the stoichiometric ratio :math:`r = f N_{\text{xlinks}} / (2 N_{\text{strands}})`
across :math:`r \in \{0.65, 0.80, 1.00, 1.25\}` (each reacted to 95% of its
stoichiometric maximum conversion, :math:`p = 0.95 \min(1, 1/r)`) highlights
the asymmetry between cross-linker deficiency (:math:`r < 1`) and excess
(:math:`r > 1`). Under cross-linker deficiency (:math:`r = 0.65`), fewer
junctions connect the strands, lowering :math:`G'(\omega)` in the low-frequency
regime, whereas excess cross-linker (:math:`r = 1.25`) maintains a higher
strand conversion and modulus closer to the stoichiometric reference
(:math:`r = 1.00`). Across all :math:`r`, KPM tracks the exact spectra closely.

Representative Volume, Sample Count, and Computational Scaling
--------------------------------------------------------------
Evaluating the reference PDMS network (:math:`N = 100`, :math:`p = 0.95`,
:math:`r = 1.0`) across cubic box sizes :math:`L \in [10, 36]\,\text{nm}`
(from :math:`\sim 2.2\times 10^3` up to :math:`\sim 1.04\times 10^5` beads,
:math:`n_{\text{samples}} = 12` realizations per box size) illustrates why KPM
is essential for realistic RVE sizes. Full eigenvalue decomposition scales as
:math:`\mathcal{O}(N_{\text{atoms}}^3)`, becoming hundreds to thousands of
times slower than KPM by :math:`L = 20\,\text{nm}` (:math:`\sim 17{,}800`
beads), whereas KPM scales linearly as :math:`\mathcal{O}(N_{\text{atoms}})`
and evaluates :math:`L = 36\,\text{nm}` (:math:`\sim 1.04\times 10^5` beads)
in :math:`\sim 9.8\,\text{s}`. Larger boxes also suppress finite-size scatter,
reducing the number of realizations :math:`n_{\text{samples}}` required for a
target 95% confidence interval.
