get_gamma_factor(self: pylimer_tools_cpp.MEHPSimulator, b02: SupportsFloat | SupportsIndex = -1.0, nr_of_chains: SupportsInt | SupportsIndex = -1) → float¶

Compute the average topological Gamma factor sum(gamma_factors) / denom.

Parameters:

  • b02¶ – Mean-squared bond length \(b_0^2\) (defaults to network bond length squared).

  • nr_of_chains¶ – Denominator for averaging. When < 1 (default -1), divides by network.nr_of_strands — note that in EntanglementMode.SPRING, nr_of_strands includes entanglement coupling springs, so comparing MERGED_LINKS vs. SPRING with the default -1 is not apples-to-apples. Pass 1 or use np.sum(get_gamma_factors(b02)) when computing shear modulus.

get_gamma_factors(self: pylimer_tools_cpp.MEHPSimulator, b02: SupportsFloat | SupportsIndex = -1.0) → Annotated[numpy.typing.NDArray[numpy.float64], '[m, 1]']¶

Compute the per-spring topological Gamma factors \(\Gamma_i = \mathbf{r}_i^2 / (N_i b_0^2)\).

Summing this vector (np.sum(sim.get_gamma_factors(b02))) gives the unnormalized total needed to compute the shear modulus \(G = (k_B T / V) \sum_i \Gamma_i\).

Parameters:

b02¶ – Mean-squared bond length \(b_0^2\) (defaults to network bond length squared).

Compute the per-spring directional Gamma factors \(\Gamma_{i,\alpha} = r_{i,\alpha}^2 / (N_i b_0^2)\).
