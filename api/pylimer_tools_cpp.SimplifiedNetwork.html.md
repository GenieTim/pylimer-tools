# SimplifiedNetwork

### *class* pylimer_tools_cpp.SimplifiedNetwork

Bases: `pybind11_object`

A more efficient structure of the network for use in MEHP,
namely [`MEHPForceRelaxation`](pylimer_tools_cpp.MEHPForceRelaxation.md#pylimer_tools_cpp.MEHPForceRelaxation).
Consists usually only of the crosslinkers.
